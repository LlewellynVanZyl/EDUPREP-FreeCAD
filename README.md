# EDUPREP-FreeCAD
FreeCAD portable setup scripts and training resources for EDUPREP training.

## FreeCAD Portable Installation

This repository provides an automated installer for FreeCAD 1.1.4 Portable.

### Installation instructions

1. Download `FreeCAD.bat` from the Install folder.
2. Save the batch file to your computer.
3. Double-click the batch file.
4. Wait for the download and extraction to complete.
5. A FreeCAD shortcut will be created on your Desktop.

**Requirements:**
- Windows 10 or Windows 11 (64-bit).
- Internet connection.
- Sufficient free disk space.

No administrator privileges or conventional FreeCAD installation should be necessary.

### Features

- Downloads the official FreeCAD portable package.
- Extracts FreeCAD automatically.
- Creates a Desktop shortcut.
- Avoids unnecessary downloads and extraction when run again.
- Can resume an incomplete installation.
